Status data refreshes automatically the moment a tracked build starts or finishes, via a notification the build workflow sends directly to this repo, and on every push to main. There is currently no periodic background re-check — if a repo hasn't built recently, its card simply reflects the last known state, which is expected. Viewing this page never consumes any GitHub API quota, since it only reads a static published file. "Trigger update" opens the workflow's page on GitHub, where you can click "Run workflow" if you have write access to this repo (the browser can't kick off a run itself without embedding a credential in this public page, which we deliberately don't do).
